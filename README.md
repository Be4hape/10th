# 내일배움캠프 데이터 분석 과정

데이터 분석가로 성장하기 위해 Python, SQL, Tableau, 머신러닝, 데이터 시각화, 대용량 데이터 처리까지 전 과정을 실습 중심으로 훈련한 과정입니다.  
단순히 강의를 수강하는 데서 끝나지 않고, 실제 데이터를 기반으로 문제를 정의하고 분석하며, 프로젝트 결과를 대시보드와 발표 자료로 정리하는 경험을 쌓았습니다.

---

## 과정 소개

내일배움캠프에서는 데이터 분석의 전체 흐름을 반복적으로 경험했습니다.

- 데이터를 수집하고 정제하는 전처리 과정
- SQL과 Python을 활용한 탐색적 데이터 분석(EDA)
- 통계 검증과 머신러닝 모델링
- Tableau / Streamlit 기반 대시보드 및 결과 시각화
- 프로젝트 발표와 문서화를 통한 스토리텔링

이 과정을 통해 단순히 코드를 작성하는 수준을 넘어,  
**데이터를 기반으로 문제를 정의하고 의사결정에 도움이 되는 결과로 정리하는 역량**을 훈련했습니다.

### 5. 프로젝트 중심 협업
- 팀 프로젝트 수행
- 역할 분담 및 일정 관리

## 주요 프로젝트

### PUBG 게임 데이터 분석
- 대용량 게임 로그(하루 크롤링 기준 20GB)를 Parquet 기반으로 재구성하여 분석 효율 개선
- 유저 행동 클러스터링, 맵 상성 분석, Stress Index 분석 수행
- 이상치 기반 핵 의심 유저 탐지를 통해 운영 인사이트 도출
- 게임 로그를 운영 지표로 바꾸는 분석 경험 축적

### 이터널 리턴 게임 데이터 분석
- 유저·아이템·밸런스 분석 프로젝트 수행
- 아이템 코드 크롤링 및 매핑, Tableau 대시보드 구축
- 운영진이 주요 밸런스 지표를 빠르게 파악할 수 있는 모니터링 체계 설계

### 에어비앤비 숙소 가격 예측모델 구축
- EDA, 통계 검증, 머신러닝 모델링 수행
- CatBoost + Optuna 기반 성능 개선
- Streamlit 대시보드를 통해 예측 결과를 직관적으로 제공

### H&M 고객 매출 데이터 분석
- 시즌성 및 VIP 고객군 중심 가설 검증 수행
- 고객 세그먼트와 구매 패턴 분석
- 데이터 기반 마케팅 방향성 제안

## 내가 중요하게 생각한 점

내일배움캠프를 진행하면서 가장 중요하게 생각한 것은  
**“분석 결과를 만드는 것”이 아니라 “의미 있는 질문을 정의하고, 설득력 있게 설명하는 것”** 이었습니다.

그래서 프로젝트를 진행할 때도 아래를 계속 고민했습니다.

- 이 분석이 왜 필요한가?
- 어떤 데이터가 이 질문에 답할 수 있는가?
- 결과를 어떻게 해석해야 하는가?
- 이 결과가 실제 의사결정에 어떻게 연결될 수 있는가?

이 과정 덕분에 단순한 분석 실습을 넘어,  
**문제를 구조화하고 결과를 전달하는 데이터 분석가의 기본기**를 쌓을 수 있었습니다.
